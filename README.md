# Starlight CLI

The Starlight CLI connects a macOS user’s own local Codex installation to their Starlight workspace. It keeps pairing credentials in macOS Keychain and can run the Codex driver as a per-user LaunchAgent.

The CLI is a thin client. Starlight’s hosted service remains responsible for account authorization, workspace isolation, durable sessions and turns, approvals, spend controls, provider routing, and recovery.

The package is under active development and is not yet published to npm.
